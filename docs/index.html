Sobre o Projeto

O SUS Data Explorer é um sistema open-source que simplifica o acesso aos bancos públicos do SUS, gera insights reproduzíveis e permite evolução colaborativa.

🎯 Pilares

  • AI First: Desenvolvimento assistido por IA
  • Mobile First: Interface responsiva e acessível
  • Community First: Open source com documentação completa
